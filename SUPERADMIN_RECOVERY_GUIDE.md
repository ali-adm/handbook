# Руководство по восстановлению доступа к админке

## 🔐 Система доступа

Приложение имеет два уровня административного доступа:

### **Обычный администратор (admin)**
- **Логин**: `admin`
- **Пароль**: Может быть изменен через панель администратора
- **Функции**: Полное управление телефонным справочником

### **Суперадмин (sadmin) - резервный доступ**
- **Логин**: `sadmin`
- **Пароль**: Управляется через переменную окружения
- **Назначение**: Восстановление доступа при потере пароля `admin`

## 🚨 Восстановление доступа

### Ситуация 1: Забыт пароль администратора (admin)

1. **Войдите как суперадмин**:
   ```
   Логин: sadmin
   Пароль: superadmin123 (по умолчанию)
   ```

2. **Смените пароль администратора**:
   - В панели администратора нажмите "Сменить пароль"
   - Введите текущий пароль суперадмина
   - Установите новый пароль для администратора

3. **Выйдите и войдите как admin** с новым паролем

### Ситуация 2: Забыт пароль суперадмина (sadmin)

1. **Используйте скрипт смены пароля**:
   ```bash
   python change_superadmin_password.py НовыйПароль123
   ```

2. **Пересоберите контейнер**:
   ```bash
   docker compose up --build -d
   ```

3. **Войдите с новым паролем**:
   ```
   Логин: sadmin
   Пароль: НовыйПароль123
   ```

## 🔧 Скрипт смены пароля суперадмина

### Установка зависимостей (если нужно):
```bash
pip install werkzeug
```

### Использование:
```bash
# Изменить пароль суперадмина
python change_superadmin_password.py MySecurePassword123

# После изменения пересобрать контейнер
docker compose up --build -d
```

### Файлы скрипта:
- `change_superadmin_password.py` - основной скрипт
- `docker-compose.yml` - конфигурация с паролем

## ⚠️ Важные замечания

### Безопасность:
- Храните пароль суперадмина в надежном месте
- Регулярно меняйте пароли
- Не используйте простые пароли

### Рекомендации по паролям:
- Минимум 8 символов
- Сочетание букв, цифр и специальных символов
- Не используйте одинаковые пароли для admin и sadmin

### Резервное копирование:
- Регулярно делайте бэкап базы данных
- Храните копию docker-compose.yml с актуальными настройками

## 🛠️ Технические детали

### Переменные окружения:
```yaml
# В docker-compose.yml
environment:
  - SUPERADMIN_PASSWORD=your_superadmin_password
```

### База данных:
- Пароли хранятся в хэшированном виде
- Изменения применяются при перезапуске контейнера
- База данных сохраняется в volume

## 📞 Контакты для экстренных случаев

Если возникли проблемы с доступом:
1. Проверьте правильность ввода пароля
2. Убедитесь, что контейнер запущен
3. Проверьте логи контейнера: `docker compose logs backend`
4. Используйте скрипт восстановления

---

**Важно**: Суперадмин предназначен только для восстановления доступа. Для повседневной работы используйте обычного администратора.
