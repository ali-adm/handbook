# Телефонный справочник

Веб-приложение для управления телефонным справочником сотрудников с современным интерфейсом и расширенными функциями.

## Основные функции

- 📋 **Просмотр сотрудников** - Полный список с фото и контактными данными
- 🔍 **Умный поиск** - Поиск по всем полям (ФИО, отдел, должность, телефоны, email)
- 🎛️ **Фильтрация** - Фильтрация по отделам и другим критериям
- 📊 **Сортировка** - Сортировка по всем колонкам таблицы
- 👨‍💼 **Админ-панель** - Полное управление данными сотрудников
- 📤 **Импорт данных** - Поддержка Excel (.xlsx) и CSV файлов
- 📥 **Экспорт PDF** - Генерация телефонного справочника в PDF формате
- 📸 **Загрузка фото** - Загрузка и отображение фотографий сотрудников
- 🔐 **Безопасность** - Аутентификация администратора
- 🌙 **Темная тема** - Переключение между светлой и темной темами
- 🔄 **Перетаскивание** - Изменение порядка сотрудников в списке

## Технологический стек

- **Backend**: Flask, SQLAlchemy, Flask-Login
- **Frontend**: React, Material-UI
- **База данных**: SQLite
- **Импорт/экспорт**: pandas, ReportLab
- **Контейнеризация**: Docker

## Быстрый старт

### Запуск в Docker (рекомендуется)

```bash
# Сборка и запуск контейнеров
docker-compose up --build

# Для запуска в фоновом режиме
docker-compose up -d --build
```

Приложение будет доступно по адресу: http://localhost:3000

### Запуск в режиме разработки

#### Backend (Flask)
```bash
cd backend
pip install -r requirements.txt
python app.py
```
Backend будет доступен по адресу: http://localhost:5000

#### Frontend (React)
```bash
cd frontend
npm install
npm run dev
```
Frontend будет доступен по адресу: http://localhost:3000

## Использование

### Публичный доступ
- Откройте http://localhost:3000
- Используйте поиск и фильтры для нахождения сотрудников
- Экспортируйте данные в PDF

### Админ-панель
- Нажмите кнопку "Войти" в правом верхнем углу
- **Логин**: `admin`
- **Пароль**: `admin123`
- Добавляйте, редактируйте и удаляйте сотрудников
- Импортируйте данные из Excel/CSV файлов
- Загружайте фото сотрудников
- Изменяйте порядок сотрудников с помощью перетаскивания

### Настройки администратора

#### Учетные данные по умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin123`

#### Изменение пароля администратора:

**Способ 1: Через базу данных SQLite**
```bash
# Подключиться к базе данных
sqlite3 backend/instance/handbook.db

# Обновить пароль
UPDATE user SET password_hash = 'новый_хэш' WHERE username = 'admin';
```

**Способ 2: Через Python скрипт**
```python
from werkzeug.security import generate_password_hash

# Сгенерировать новый хэш пароля
new_password = 'ваш_новый_пароль'
new_password_hash = generate_password_hash(new_password)

# Обновить в базе данных
```

**Способ 3: Пересоздать администратора**
Удалите файл базы данных `backend/instance/handbook.db` и перезапустите приложение. Администратор будет создан заново с паролем по умолчанию.

#### Переменные окружения для настройки:
- `SECRET_KEY` - секретный ключ Flask (обязательно изменить в продакшене)
- `DATABASE_URL` - URL базы данных (по умолчанию: sqlite:///handbook.db)

### Импорт данных
1. Войдите в админ-панель
2. Нажмите "Импорт из файла"
3. Выберите файл в формате Excel (.xlsx) или CSV
4. Столбцы должны соответствовать: Отдел, ФИО, Должность, № вн., общ. №, городской №, email

## API Endpoints

- `GET /api/employees` - список сотрудников
- `POST /api/employees` - создание сотрудника (только админ)
- `PUT /api/employees/:id` - редактирование (только админ)
- `DELETE /api/employees/:id` - удаление (только админ)
- `POST /api/import` - импорт данных (только админ)
- `GET /api/export/pdf` - экспорт в PDF
- `GET /api/departments` - список отделов

## Безопасность

- Аутентификация через Flask-Login
- Пароли хэшируются с помощью Werkzeug
- CORS настроен для фронтенда
- В продакшене измените SECRET_KEY в docker-compose.yml
