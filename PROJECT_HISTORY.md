## Общая информация о приложении

### Архитектура приложения
- **Frontend**: React + Material-UI (Vite)
- **Backend**: Flask + SQLAlchemy
- **База данных**: SQLite
- **Контейнеризация**: Docker + Docker Compose

### Основные функции
1. **Управление сотрудниками**: CRUD операции (создание, чтение, обновление, удаление)
2. **Поиск и фильтрация**: Поиск по всем полям, фильтрация по отделам
3. **Импорт данных**: Поддержка Excel (.xlsx) и CSV файлов
4. **Экспорт PDF**: Генерация телефонного справочника в PDF формате
5. **Темная тема**: Переключение между светлой и темной темами
6. **Перетаскивание**: Изменение порядка сотрудников в списке

### Настройки администратора

#### Учетные данные по умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin123`

#### Изменение пароля администратора:
1. **Через базу данных SQLite**:
   ```bash
   sqlite3 backend/instance/handbook.db
   ```
   ```sql
   UPDATE user SET password_hash = 'новый_хэш' WHERE username = 'admin';
   ```

2. **Через Python скрипт**:
   ```python
   from werkzeug.security import generate_password_hash
   new_password_hash = generate_password_hash('новый_пароль')
   # Обновить в базе данных
   ```

#### Переменные окружения:
- `SECRET_KEY` - секретный ключ Flask
- `DATABASE_URL` - URL базы данных (по умолчанию: sqlite:///handbook.db)

### Инструкции по запуску

#### Локальная разработка:
```bash
# Backend
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py

# Frontend
cd frontend
npm install
npm run dev
```

#### Продакшен (Docker):
```bash
docker compose up --build
```

#### Доступ к приложению:
- **Frontend**: http://localhost:80
- **Backend API**: http://localhost:5000/api

### Поддерживаемые форматы импорта
- **Excel**: .xlsx файлы с колонками: Отдел, ФИО, Должность, № вн., общ. №, городской №, email
- **CSV**: CSV файлы с аналогичными колонками

### Особенности реализации
- **Аутентификация**: Flask-Login для сессионной аутентификации
- **CORS**: Настроен для взаимодействия frontend/backend
- **Загрузка файлов**: Встроенный функционал Flask (без Flask-Uploads)
- **PDF генерация**: ReportLab с поддержкой кириллицы
- **Сортировка**: Поддержка сортировки по всем колонкам таблицы
